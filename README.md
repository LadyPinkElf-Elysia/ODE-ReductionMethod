# 化归视角下的常数变易法与待定系数法

> **为什么它们都是自然的？**
> 从小学算术到高阶微分方程，一个统一的思想贯穿始终——**化归**。

---

## 文章简介

许多同学学微分方程时，觉得**常数变易法**和**待定系数法**像凭空出现的“魔术”：设一个特解形式代进去，就解出来了——步骤记住了，心里却不踏实。

本文揭开这层面纱：这些方法都不是天降的，而是**化归**的自然产物。化归说白了，就三招——

- **不断分解**：把大问题分解成不可再分解的小问题（如降阶）；
- **有限叠加**：把大问题看成有限个小问题的叠加（如“通解=齐次+特解”、猜形）；
- **换角度**：把同一个问题换成另一个角度来理解（如换元、打包、用复数）。

全文从小学算术出发，把这三招一路用到底：非齐次拉回齐次、高阶降成一阶、复杂函数拆成简单形状。每个“天马行空”的步骤，背后都有一条清晰的逻辑链。

## 核心思想

> **化归** = 把不会的变成会的，翻来覆去就三招：

- **不断分解**：高阶方程拆成一阶（降阶）
- **有限叠加**：非齐次 = 齐次 + 特解；特解 = 基础形状的拼合（猜形）
- **换角度**：减法换加法、换元、打包、复数、封装

**常数变易法**：从解空间基底出发，把齐次通解里的常数“变易”为函数，构造特解。
**待定系数法**：从非齐次项形式出发，借封闭性猜特解形式，用代数代替积分。
**积分因子法**：把高阶分解成一阶，用积分因子求解——不挑非齐次项，只要积分积得出。

三者殊途同归，都服务于同一个目标：**找到那个“补齐项” $y^*$，让不会解的回到会解的。**
