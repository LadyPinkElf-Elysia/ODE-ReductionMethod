## 文章简介

许多同学在学习微分方程时，常常觉得**常数变易法**和**待定系数法**像是凭空出现的“魔术”：  
明明只是设了一个特解形式代进去，却能解出正确答案——步骤记住了，但总感觉不踏实。

本文试图揭开这层神秘面纱，**从最朴素的思想出发**，展示这两种方法其实都是**化归思想**的自然产物。

我们把不会的转化为会的，把非齐次的拉回齐次的，把未知的系数通过形式猜测确定下来——这些看似天马行空的步骤，背后都有着清晰的逻辑链条。

## 核心思想

> **化归** = 把未知的问题转化为已知的问题

- 减法不会？ → 化成加法  
- 除法不会？ → 化成乘法  
- 非齐次方程不会解？ → 化成齐次方程（补齐特解）  
- 变系数不会解？ → 化成常系数（换元）  
- 非线性不会解？ → 化成线性（特殊情形，如伯努利）

**常数变易法**：从解空间基底出发，将齐次通解中的常数“变易”为函数，构造特解。  
**待定系数法**：从非齐次项的形式出发，利用封闭性猜测特解形式，用代数代替积分。

**两者殊途同归，都服务于同一个目标——找到那个“补齐项” $y^*$，让非齐次方程回归齐次。**
